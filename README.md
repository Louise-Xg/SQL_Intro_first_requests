# SQL_Intro_first_requests

Dans le cadre de la formation DWWM chez Simplon x Wild Code School.

4 exercices pour introduire le SQL et ses premières requêtes, chaque branche représente un exercice :

- Création de tableaux et importation des données
- Sélection/Ordonner/Trier des informations dans les tableaux
- Remplacer/Supprimer des données dans les tableaux
- Établir un MCD

Ici, les tableaux wizard et school ont été renommés en wizard2 et school2.

Difficultés rencontrés :

- Passage du syntaxe mySQL en PostgreSQL
- L'utilisation de offset
